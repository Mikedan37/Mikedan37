## Featured Work

### [BlazeDB](https://github.com/Mikedan37/BlazeDB)

Encrypted, in-process database engine written in Swift.

Includes WAL-backed durability, crash recovery, transactions, indexing, live queries, Linux support, and a documented C ABI.

### [SeekerScore](https://www.seekerscore.com)

Production platform for résumé analysis, job discovery, and application workflows.

Built with live job ingestion, background workers, analytics, observability, and reliability tooling.
